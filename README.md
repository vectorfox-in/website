# Graphic Design Portfolio

A modern and interactive personal portfolio website created to showcase my work, skills, creative projects, and design experience as a Graphic Designer.

The website is built using **HTML, CSS, and Vanilla JavaScript**, with a strong focus on clean visual design, typography, responsive layouts, smooth animations, and an engaging user experience.

## ✦ Features

* Modern creative-studio inspired design
* Responsive layout for desktop, tablet, and mobile
* Interactive project portfolio
* Project categories and filtering
* Project search functionality
* Detailed case studies
* Project image galleries
* Full-screen image lightbox
* Custom cursor interactions
* Smooth scroll animations
* Scroll-based section reveals
* Dark/light mode support
* Mobile-friendly navigation
* Contact and newsletter sections
* Keyboard support for image navigation

## ✦ Design Focus

The portfolio focuses on **graphic design, branding, visual identity, typography, packaging, print design, and digital design**. The visual direction combines minimalism, editorial layouts, bold typography, large imagery, whitespace, and subtle micro-interactions to create a premium creative-studio experience.

## ✦ Technologies

* HTML5
* CSS3
* JavaScript
* CSS Grid & Flexbox
* Intersection Observer API
* Responsive Web Design
* Local Storage

The project is designed to remain lightweight and does not rely on large JavaScript frameworks.

## ✦ Purpose

This portfolio serves as a central platform to present my creative work and professional capabilities to **clients, recruiters, design agencies, and potential collaborators**.

The goal is to create a digital experience that reflects the same attention to detail, creativity, and visual thinking that goes into my design work.
